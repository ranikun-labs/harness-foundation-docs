# Decision Log

Decision Log는 승인된 결정과 변경 이력을 요약하는 색인이다. ADR을 대체하지 않는다.

## 책임

- 결정 일자, 상태, 관련 ADR, Source Input, 영향 범위 요약
- Master, Roadmap, Architecture, Product 문서 변경 이력 추적
- Session Handoff보다 높은 우선순위의 결정 요약 제공

## 허용 내용

- 승인된 결정의 요약
- 제안, 반려, 대체된 결정의 상태 기록
- 관련 ADR과 Commit 링크

## 금지 내용

- ADR 없이 복잡한 결정의 근거를 축약해 확정하는 행위
- 실제 제품 결정의 추론
- 승인되지 않은 Source Input의 canonical 반영
