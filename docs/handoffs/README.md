# Session Handoffs

이 디렉터리는 작업 세션 간 인수인계 문서를 관리하는 위치다.

## 책임

- 현재 목표, 진행 상태, 열린 이슈, 다음 행동 기록
- 다음 세션이 읽어야 할 Source of Truth와 파일 목록 정리
- Chat Session 맥락을 Git 문서로 최소한만 보존

## 허용 내용

- 작업 중단 시점의 인수인계
- 확인된 결정과 가정의 분리 기록
- 다음 작업자가 읽어야 할 파일 목록

## 금지 내용

- Session Handoff를 canonical 제품 문서로 사용하는 행위
- 승인되지 않은 제품 결정 확정
- 실제 제품 히스토리의 임의 보완

## 템플릿

새 Handoff는 [templates/session-handoff-template.md](../../templates/session-handoff-template.md)를 사용한다.
