# Product Documents

이 디렉터리는 승인된 제품 및 Extension 세부 문서를 관리하는 위치다.

## 책임

- Master Document보다 세부적인 제품 설명 관리
- 승인된 범위, 용어, 정책과의 정합성 유지
- 관련 Source Input과 ADR 링크 관리

## 허용 내용

- 승인된 제품 세부 문서
- 승인된 Extension 문서
- superseded 또는 archived 상태의 과거 문서

## 금지 내용

- Finance 상세 구조의 추론
- 실제 제품 기능이나 구현 상태의 임의 작성
- 승인되지 않은 사용자 시나리오나 제품 아이디어
