# Roadmap Documents

이 디렉터리는 승인된 제품 및 기술 Roadmap 문서를 관리하는 위치다.

## 책임

- 명시적으로 승인된 방향, 단계, 범위 기록
- 관련 ADR, Master Document, Source Input과의 연결 유지

## 허용 내용

- 승인된 Product Roadmap
- 승인된 Technical Roadmap
- superseded 또는 archived 상태의 과거 Roadmap 문서

## 금지 내용

- 실제 Roadmap 내용의 추론
- 새로운 제품 아이디어
- 승인되지 않은 일정, 우선순위, 구현 범위
