# Master Documents

이 디렉터리는 승인된 canonical Master Document를 관리하는 위치다.

## 책임

- 현재 기준의 전체 제품 상태 설명
- 승인된 ADR, Roadmap, Architecture, Product 문서와의 정합성 유지
- Source Input이 승인된 뒤 반영된 최종 설명 관리

## 허용 내용

- canonical 상태의 Master Document
- superseded 또는 archived 상태의 과거 Master Document
- 관련 ADR과 Source Input 링크

## 금지 내용

- 승인되지 않은 제품 구조
- 실제 V1, V2, V3 상세 내용의 추론
- 구현 상태에 대한 미확인 판단
- Source Input 원문을 검수 없이 섞은 본문
